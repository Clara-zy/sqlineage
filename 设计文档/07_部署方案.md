# SQLineage 部署方案

> 版本: v1.0 | 环境: 本地开发 / 测试

---

## 1. 技术栈

| 组件 | 技术 | 开发端口 |
|---|---|---|
| 后端 | Python 3.11+ / FastAPI | 8000 |
| 前端 | React 18 / Vite | 5173 |
| 数据库 | PostgreSQL 15 (本地服务) | 5432 |
| 缓存 | Redis 7 (本地服务) | 6379 |

> **前提**: PostgreSQL 和 Redis 已在宿主机安装并运行。SQLineage 只连接已有服务，不管理其生命周期。

## 3. 环境变量 `.env`

```bash

POSTGRES_USER=sqlineage
POSTGRES_PASSWORD=your_password_here

REDIS_PORT=6379
REDIS_DB=0

# === 应用 ===

```

## 4. Makefile

```makefile
.PHONY: install dev start stop clean

# === 安装依赖 ===
install:
	cd backend && pip install -r requirements.txt
	cd frontend && npm install

# === 开发模式启动 ===
dev:
	@echo "Starting backend (port 8000)..."
	cd backend && uvicorn app.main:app --reload --host 0.0.0.0 --port 8000 &
	@echo "Starting frontend (port 5173)..."
	cd frontend && npm run dev &
	@echo "Backend:  http://localhost:8000"
	@echo "Frontend: http://localhost:5173"

# === 仅启动后端 ===
backend:
	cd backend && uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

# === 仅启动前端 ===
frontend:
	cd frontend && npm run dev

# === 停止所有 ===
stop:
	@echo "Stopping services..."
	-pkill -f "uvicorn app.main"
	-pkill -f "vite"

# === 数据库初始化 ===
db-init:
	cd backend && python -m app.db_init

# === 运行测试 ===
test:
	cd backend && pytest tests/ -v

# === 代码检查 ===
lint:
	cd backend && ruff check .
	cd frontend && npm run lint

# === 清理 ===
clean:
	find . -type d -name __pycache__ -exec rm -rf {} + 2>/dev/null || true
	rm -rf frontend/dist frontend/node_modules/.vite
```

## 5. 初始化步骤

```bash
# 1. 创建数据库
psql -U postgres -c "CREATE USER sqlineage WITH PASSWORD 'your_password';"
psql -U postgres -c "CREATE DATABASE sqlineage OWNER sqlineage;"

# 2. 配置环境变量
cp .env.example .env
# 编辑 .env，填入实际密码

# 3. 安装依赖
make install

# 4. 初始化数据库表 + 默认管理员
make db-init

# 5. 启动开发服务
make dev
```

---

## 6. db-init 脚本逻辑

```python
# backend/app/db_init.py
"""
1. 读取 .env 配置
2. 连接 PostgreSQL
3. 执行 schema 迁移 (CREATE TABLE IF NOT EXISTS ...)
4. 插入默认管理员 admin / nbkknb (bcrypt)
5. 打印初始化结果
"""
```

> 初期用 DDL 脚本直接执行（`CREATE TABLE IF NOT EXISTS`）。后续如果频繁变更，引入 Alembic。

## 7. 生产环境（预留）

如果后续上线，在已有 `docker-compose.yml` 基础上添加应用镜像即可：

```yaml
# docker-compose.prod.yml
services:
  db:      # pg:15
  redis:   # redis:7
  backend: # python:3.11 + uvicorn (无 --reload)
  frontend:# nginx 代理 + vite build 产物
```

本地开发模式不受影响——Makefile 仍然可用，`make dev` 连本地服务。两者互不干扰。

## 8. 常见问题

| 问题 | 解决 |
|---|---|
| `make stop` 杀不掉进程 | `pkill -9 -f "uvicorn\|vite"` |
| 前端 Vite 报 proxy 错误 | 检查 `vite.config.ts` 中 proxy 指向 `http://localhost:8000` |
| Redis 未安装 | `brew install redis`(macOS) / `apt install redis`(Linux) |
| macOS 上 PostgreSQL 权限错误 | `createuser -s sqlineage` |
