# SQLineage 枚举值设计

> 版本: v1.0

---

## 1. 概述

字段枚举值描述一个字段公民的合法取值集合。它服务于：
- 前端 DAG 中条件节点的可读性
- 血缘校验（eq/in 中字面量是否在枚举范围内）
- AI 语义推断的辅助信息

---

## 2. DDL COMMENT 格式

```
trans_status STRING COMMENT '交易状态 ENUM(SUCCESS,FAIL,REFUND)'
gender STRING COMMENT '性别 ENUM(M,F)'
```

解析规则：`ENUM(` 到 `)` 之间按逗号分隔提取值列表。

---

## 3. 数据库表

```sql
field_enums {
    id              SERIAL PRIMARY KEY
    field_hash      VARCHAR(16) NOT NULL  — fields.hash
    enum_values     JSONB NOT NULL        — ["SUCCESS","FAIL","REFUND"]
    source          ENUM('ddl_comment','manual','ai_inferred') NOT NULL
    status          ENUM('active','deprecated') NOT NULL DEFAULT 'active'
    deprecated_at   TIMESTAMPTZ
    deprecated_reason TEXT
    created_at      TIMESTAMPTZ NOT NULL DEFAULT now()
}
```

索引: `idx_fe_hash_status ON (field_hash, status)`

---

## 4. 枚举值的产生

### 4.1 建表时解析 COMMENT

`table_columns.column_comment` 中包含 `ENUM(...)` 时，解析并写入 `field_enums`，source=ddl_comment。

### 4.2 专家手动录入

通过 API 或 DAG 前端手动设置某个字段的枚举值，source=manual。

### 4.3 AI 推断

语义推断时，AI 可建议枚举值，经专家确认后写入，source=ai_inferred。

---

## 5. 枚举值的继承

- **`alias` 节点**：直接复用被包装字段的枚举值
- **`JOIN` 节点**：复用被包装字段的枚举值
- **其他表达式**：不继承（如 `nvl(a,'未知')` 引入了新字面量）

---

## 6. 枚举校验

- **触发**：`eq` / `neq` / `in` / `not_in` 条件中，左侧引用已注册枚举的字段，右侧为字面量
- **行为**：字面量值不在枚举列表中 → 产生**警告**（非致命错误）
- **警告信息**：`字段 {hash} 的枚举值 [{...}] 不包含字面量 '{value}'`

---

## 7. 不做的

- ❌ 从查询字面量反向收集枚举（噪音大）
- ❌ `field → literal` 显式关联
